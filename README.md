# Hospital Management System

A modern Hospital Management System built with React + Vite on the frontend and Node.js + Express on the backend.

## Features
- Admin dashboard with statistics and charts
- Patient management
- Doctor management
- Appointment management
- Billing/invoices
- Pharmacy inventory
- Laboratory tests
- Room/IPD management
- Search and filters
- Responsive sidebar layout
- Demo data for quick presentation

## Run the project

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Open the URL shown by Vite, normally http://localhost:5173

### Backend
Open another terminal:
```bash
cd backend
npm install
npm run dev
```
API runs on http://localhost:5000

The frontend works with demo data by default, so it can be demonstrated immediately. The Express API provides sample REST endpoints for patients, doctors and appointments.
